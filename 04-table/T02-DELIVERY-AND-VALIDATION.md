# T02: delivery and validation map

Internal design, 30October 2026. This maps work and evidence needs without inventing costs, staff availability or customer outcomes.

| Work object | Necessary work | Evidence of fulfilment to define |
| --- | --- | --- |
| DW01: Research edition | Define audience/decision scope, collect actual evidence, code/review, write/design and finalise with rights/currentness checks. Research and editorial owner; actual capacity not confirmed. | Versioned publishable evidence and complete contracted publication; do not count future sponsor-specific editions as already funded. |
| DW02: Reading path and existing tools | Choose supported sections/contrasts and relevant existing framework/templates for the stated use. Research/editorial preparation; actual hours unknown. | A short task-based route through the edition, without new bespoke study or invented case evidence. |
| DW03: Bounded briefing if included | Set user/audience, agenda, preparation, format and follow-up boundary; identify a capable available person. Briefing/service owner; no staffed analyst bench or time promise presumed. | Defined service and its complete labour cost; capacity and price assessed later. |
| DW04: Use/recognition assets | Specify material/version, allowed use, source/participant constraints, funding statement and logo permissions where relevant. JGA publication/commercial owner and appropriate rights review. | Actual agreed use/asset record; no default third-party rights or participant data access. |
| DW05: Practitioner research/peer route | Screen relevant fit, choose practical input/meeting mode, apply existing permission and count policy. Research/participation/moderation owner; tools and arrangements not approved by this map. | Actual eligible usable permitted contribution and separately tracked peer/event participation. |
| DW06: Cycle follow-through if included | Prepare a short note with appropriate takeaways, limits and open questions; review for indirect identification. Editorial/moderation follow-through capacity to test and cost. | A scoped optional benefit; no unlimited advice or recurring output. |
| DW07: Event increment if chosen | Add recruitment, host/moderator seats, venue/hospitality, access, travel, timing and cancellation work. Event/programme owner and funding; no supplier enquiry or booking made. | Incremental fully loaded resource/cash model against the research-only route, not all sales attributed to dinners. |
| DW08: Sales/administration and later upkeep | Define proposal/contract/invoice/fulfilment/correction work, edition period and any genuinely chosen future refresh. Commercial/administrative/editorial owners, not an assumed recurring team. | Count bundled licences once; distinguish contracted, invoiced, received and fulfilled; no automatic renewal. |

## What future input can and cannot show

Use the existing six buyer and six member questions selectively. A real prior purchase, actual decision and specific unmet evidence need are more informative than general enthusiasm. A request for a scoped proposal is a possible next decision; it is not a signed order. Receipt of money is not the same as delivery of a permissioned asset or useful benefit.

| Hypothesis | Useful input to seek | Counter-signal |
| --- | --- | --- |
| H01 Research use | Actual decision/user, alternatives, missing input and wanted output/use | Equivalent free/internal material is enough, or evidence cannot support the task |
| H02 Funding | Real use, acceptable independent evidence, purchase route and defined rights | Value depends on unagreed private access, favourable findings or unsuitable recruitment |
| H03 Practitioner value | Recent relevant need, peer fit, permitted practical input and valued follow-through | Time/permission/format prevents participation or value is hospitality only |
| H04 Event increment | Specific benefit over research-only/remote/written alternatives | Added travel/cost/burden with no distinct benefit or delivery/funding route |

The existing Table cap is up to four substantive exploratory contribution events; variation is purposeful, not a representative survey. Preserve objections, unknowns and missing information. No success percentage, fixed validation score, price elasticity or market forecast is appropriate from this design.
