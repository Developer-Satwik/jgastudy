Download HMRC's Basic PAYE Tools
Basic PAYE Tools is free payroll software from HM Revenue and Customs (HMRC) for businesses with fewer than 10 employees.
This guide is also available in Welsh (Cymraeg).
What it does
The software allows you to perform most payroll tasks, including working out the tax and National Insurance for your employees and sending this information to HMRC.
If you have payroll software that cannot do certain tasks, you can use Basic PAYE Tools alongside it to:
check a new employee’s National Insurance number
send an Employer Payment Summary
Basic PAYE Tools has some limitations. It is not designed for agents or bookkeepers. Other payroll software is available.
Before you start
You must be registered with HMRC as an employer and have a login for PAYE Online before you can use Basic PAYE Tools.
Download the latest version of Basic PAYE Tools
The software will work with most newer computers and up-to-date browsers.
If your computer is part of a network of computers, you may be unable to download any software. Contact your network’s IT service for support.
If you’re having issues downloading or opening Basic PAYE Tools, check the service availability and issues for what to do.
Download Basic PAYE Tools for Windows (Zip, 187MB)
Download Basic PAYE Tools for Mac (Zip, 172MB)
Download Basic PAYE Tools for Linux (Zip, 182MB)
The guide to using Basic PAYE Tools explains how to download, install and use the software to start sending payroll information to HMRC.
Updating the software
The latest version of Basic PAYE Tools will check for updates automatically, usually when the tax year changes, or new rules come in. You must make sure you select the update option in your tool settings when you first install the software.
The latest version is 26.1.26134.173934. The number displays within ‘Settings’ in the top-right corner of the tool.
Do not uninstall the version of the software you’ve been using because you’ll lose payroll data.
Minimum hardware requirements
The minimum hardware specification you need to use Basic PAYE Tools is:
Intel(R) Core (i3/i5/i7/i9), AMD equivalent, or greater
4 GB RAM
80 GB, 7200 rpm hard disk
DirectX 11 (or greater) capable video hardware
Supported operating systems
The following operating systems are supported:
Windows 10 and 11
macOS version 15 ‘Sequoia’ and 26 ‘Tahoe’
Ubuntu Linux version 24.04 LTS and 25.10
Only 64-bit Intel/AMD compatible versions of these operating systems are supported. MacOS is also supported on Apple Silicon processors.
Supported browsers
You can use the following browsers if you need assistive software support:
Microsoft Edge (Windows only)
Google Chrome
Mozilla Firefox
Apple Safari (macOS only)
Other requirements
You need an active internet connection for:
submitting payroll information online
automatic updates
email features
web links
You’ll need Adobe Reader or a compatible equivalent to open printable forms.
