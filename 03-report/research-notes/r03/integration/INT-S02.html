Manage your Staffology Payroll integrations

Open the Staffology Payroll screen in Staffology HR

To manage the integration between your HR and Payroll companies:

  1. Go to System Tools > Utilities > Payroll >Staffology Payroll.

Actions drop-down

At the top-right of the screen, select Actions to:

  • Open the Audit

  • Open and review synced data in the Integration Log

  • Update the API Key

    Integration Log

    In the Integration Log, you can track data syncing between your systems, including:

    • Data that failed to sync

    • The reason for any failures

    You can also filter the log by date range and select a specific payroll company to review.

    Update API Key

    You can enter a new API key at any time. Updating the key does not affect your existing integrations.

    To find your key:

    1. Open Staffology Payroll.

    2. Select your Profile icon.

    3. Choose API Keys.

Add a new integration

To add a new integration:

  1. Select Add Integration.

  2. Enter the required information to set up the connection between your HR and Payroll companies.

These are the same steps you completed when you first integrated your companies.

For help integrating your companies, choose one of the following:

  • Getting started as a new HR customer

  • Getting started as a new Payroll customer

  • Getting started as a new customer

  • Getting started as an existing customer with HR and Payroll (not integrated)

Company Integrations

The Company Integrations section is where you can manage your existing integrations.

To view or update an integration:

  • Select a company from the table to open a screen showing this integration

  • Use the drop-down arrow to edit or remove the integration

Include Cost Centres or Departments when syncing with Staffology Payroll

You can sync department and cost centre data from employee and company records to Payroll by selecting Activate Cost Centres sync or Activate Departments sync options.

How the sync works:

When the ID matches in Staffology Payroll, the details are replaced with the details from Staffology HR.

If the IDs do not match:

  • Company records: Cost centres or departments are added as new records in Staffology Payroll

  • Employee records: Existing cost centres or departments are replaced with the ones from Staffology HR

Once you turn on either setting, department and cost centre data syncs to Payroll automatically. Any changes you make to these fields in company or employee records are synced immediately.

Do not use this setting if using a third-party provider to manage cost centres or departments in Staffology Payroll. The sync will overwrite or duplicate records the third-party provider controls.

Find out more about syncing cost centres and departments from Staffology HR with Staffology Payroll.

Payroll Lock

Enter From and To dates to stop data from syncing to Staffology Payroll during payroll processing.

Payslips Release Timing

By entering a number inDays, you can schedule when payslips become available to employees after the pay date.

  • Leave blank to have payslips available for employees as soon as the pay run is finalised in Staffology Payroll

  • Enter 0 to make payslips available on the payment date

  • Enter 1 or more to make payslips available a specific number of days after payment date

For further help using this feature, refer to Set Payslip Release Timing.

Sync Variable Payments and deductions

Variable payments or deductions created before a pay run opened may not automatically sync to Staffology Payroll. You can manually sync these payments and deductions so that they are included in the current pay run by:

  1. Choose a Pay Period Frequency from the list.

  2. Optionally, enter a date in Include all not synced elements since.

    • Leave this blank to sync only variable payments dated within the current pay run (the default behaviour).

    • Enter a date to also sync any variable payments dated from that date up to the start of the current pay run. This date must be before the start date of the current pay run.

  3. Select Sync Variable Payments.

  4. Confirm you want to sync the variable pay elements by selecting Add Variable Elements.
